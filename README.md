# Site de déblocage WOW27

## Publication gratuite sur GitHub Pages
1. Décompressez l'archive.
2. Créez un dépôt GitHub public (ou utilisez un dépôt existant).
3. Envoyez `index.html` et `README.md` à la racine du dépôt.
4. Dans **Settings → Pages**, sélectionnez la branche principale et le dossier `/ (root)`.
5. Enregistrez et attendez la publication.

## Parcours de simulation
- Premier clic sur « Vérifier votre abonnement » : affiche « Abonnement non détecté » et masque le bouton de vérification.
- Le clic suivant sur « S'abonner » rouvre le bouton de vérification ; son deuxième clic affiche une confirmation simulée et ouvre l'étape vidéo.
- Même logique pour le like/commentaire : premier contrôle négatif, clic à nouveau sur le lien YouTube, puis deuxième contrôle avec confirmation simulée.
- Le bouton « Débloquer le lien » apparaît après la deuxième confirmation et révèle `WOW27`.

**Transparence :** ce parcours est une simulation côté navigateur. Il ne vérifie pas réellement les abonnements, les likes ni les commentaires YouTube. Le code WOW27 est présent dans le fichier public et peut être consulté par toute personne ayant accès à la page. Ce projet n'est pas un système de validation sécurisé.
